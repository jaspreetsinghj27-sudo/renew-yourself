# Premium web studio portfolio

## Visual direction
- Use an editorial split-tone system: near-black opening and closing bands balanced by warm off-white work and process sections.
- Pair a distinctive geometric display face with a precise mono accent, using oversized type and fine rules rather than decorative cards.
- Keep a single restrained chartreuse accent for key actions, labels, and interaction feedback.
- Present real-looking generated website scenes as the main visual language, with subtle grain, crisp browser chrome, and restrained depth.
